# C.S Reformas y Construcciones

Sitio estático en HTML, CSS y JavaScript. Incluye el diseño actualizado, logo, cuatro imágenes de IA, animaciones de scroll, parallax y contacto por WhatsApp.

## Archivos

- index.html: inicio.
- servicios.html: servicios.
- contacto.html: contacto.
- styles.css: estilos y diseño responsive.
- app.js: contenido, navegación y formulario de WhatsApp.
- motion.js: efectos de scroll.
- assets/: logo e imágenes.
- imagenes-ia.md: prompts usados para las imágenes.
- .nojekyll: compatibilidad con GitHub Pages.

## Usar el proyecto

Descomprimí el ZIP y subí su contenido a la raíz de tu repositorio, manteniendo la carpeta assets. El archivo index.html debe quedar en la raíz. No requiere instalación de dependencias ni compilación.

Podés abrir index.html directamente en tu navegador para revisar la web. Las rutas relativas funcionan tanto en un dominio propio como en una dirección de GitHub Pages con nombre de repositorio.

## Personalizar

El número de WhatsApp y los textos están en app.js. Los estilos están en styles.css. Las imágenes se pueden reemplazar en assets conservando sus nombres.

El formulario prepara un mensaje y abre WhatsApp: el visitante debe enviarlo. No guarda consultas ni envía correos. Las imágenes de arquitectura son ilustrativas y fueron creadas con IA. Las fuentes se cargan desde Google Fonts y requieren conexión a Internet.
